## Cài đặt

```bash
# Clone repository
git clone <repository-url>

# Di chuyển vào thư mục dự án
cd reading_book

# Cài đặt dependencies
flutter pub get

# Chạy ứng dụng
flutter run
```

## Yêu cầu

- Flutter SDK
- Dart SDK
- Android Studio / Xcode (cho development)

## Công nghệ sử dụng

- Flutter
- Firebase Messaging
- Provider/Bloc (State Management)
